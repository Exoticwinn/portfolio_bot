# Portfolio Bot

Telegram-бот-портфолио для хранения и управления проектами разработчика в SQLite.

Бот ведёт пользователя пошагово: предлагает варианты через одноразовую reply-клавиатуру, скрывает её после выбора и показывает подробные карточки проектов с emoji-интерфейсом.

## Возможности

- создание таблиц проектов, статусов, навыков и связей между ними;
- добавление начального набора статусов и навыков;
- сохранение проектов с описанием и ссылкой;
- просмотр проектов и их навыков;
- обновление статусов и удаление проектов или отдельных навыков.
- одноразовые reply-клавиатуры с кнопкой отмены;
- подробная справка по командам через `/info`;
- поиск проекта по названию и просмотр карточки через inline-кнопки.

При добавлении проекта бот запрашивает название, описание, ссылку и статус.

## Команды бота

- `/start` — приветствие и справка;
- `/info` — описание всех команд;
- `/new_project` — добавить название, описание, ссылку и статус проекта;
- `/projects` — показать проекты текущего пользователя;
- `/skills` — добавить навык проекту;
- `/update_projects` — изменить данные проекта;
- `/delete` — удалить проект.

В пошаговом режиме кнопка `Отмена 🚫` завершает текущий сценарий. Также можно отправить название проекта обычным сообщением и получить его карточку.

## Запуск

1. Установите зависимости проекта, включая `pyTelegramBotAPI`.
2. Отзовите старый токен через BotFather, создайте новый и задайте его в переменной окружения `PORTFOLIO_BOT_TOKEN`.
3. Один раз создайте и заполните базу данных командой:

```text
python logic.py
```

1. Запустите бота:

```text
python main.py
```

Файл `portfolio.db` создаётся локально и не требует отдельного сервера базы данных.

## Структура проекта

- `logic.py` — класс `DB_Manager`, SQL-запросы и демонстрационные данные;
- `config.py` — путь к базе данных и настройки приложения;
- `portfolio.db` — локальная база SQLite, создаваемая при запуске.

## Для разработчиков

- `main.py` содержит Telegram-хэндлеры, клавиатуры и пользовательские сообщения;
- `logic.py` изолирует SQL-операции в классе `DB_Manager`.
