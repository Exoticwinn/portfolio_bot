# Portfolio Bot

Учебный Python-проект для хранения и управления портфолио разработчика в базе данных SQLite.

## Возможности

- создание таблиц проектов, статусов, навыков и связей между ними;
- добавление начального набора статусов и навыков;
- сохранение проектов со ссылками на GitHub;
- просмотр проектов и их навыков;
- обновление статусов и удаление проектов или отдельных навыков.

## Структура проекта

- `logic.py` — класс `DB_Manager`, SQL-запросы и демонстрационные данные;
- `config.py` — путь к базе данных и настройки приложения;
- `portfolio.db` — локальная база SQLite, создаваемая при запуске.

## Запуск

Требуется Python 3. Запустите из корня проекта:

```bash
python logic.py
```

При первом запуске программа создаст файл `portfolio.db`, таблицы и демонстрационные записи. Результат работы будет выведен в консоль.

## Примечание

Файл `config.py` содержит пример значения токена. Реальные токены и другие секреты не следует добавлять в Git.
